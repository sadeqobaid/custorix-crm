# Custorix CRM

A comprehensive Customer Relationship Management system for managing customer interactions, sales pipeline, marketing campaigns, and support operations.

## Overview

Custorix CRM is a full-featured CRM system built with Django REST Framework backend and React/TypeScript frontend. It provides a unified platform for tracking customer data, managing leads, closing deals, and providing excellent customer service.

## Features

- **User Management**: Role-based access control with customizable permissions
- **Accounts & Contacts**: Manage business relationships and individual contacts
- **Lead Management**: Track and score potential sales opportunities
- **Sales Pipeline**: Manage opportunities through customizable sales stages
- **Marketing Campaigns**: Plan, execute, and track marketing initiatives
- **Support Tickets**: Manage customer support requests with SLA tracking
- **Invoicing & Payments**: Generate invoices and track payments
- **Reporting & Analytics**: Gain insights through comprehensive reporting

## Getting Started

Please refer to the [Installation Guide](Installation_Guide.md) for detailed setup instructions.

Quick start:

1. Clone this repository
2. Set up the database using the provided SQL script
3. Configure and start the backend server
4. Configure and start the frontend application
5. Access the application at http://localhost:5173/
