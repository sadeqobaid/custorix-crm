## Introduction

Custorix CRM is a comprehensive customer relationship management system designed to help businesses manage their customer interactions, sales pipeline, marketing campaigns, and support operations. The system provides a unified platform for tracking customer data, managing leads, closing deals, and providing excellent customer service.

## Getting Started

### Logging In

1. Open your web browser and navigate to the Custorix CRM application URL.
2. Enter your username and password on the login screen.
3. Click the "Sign In" button to access the system.

### User Interface Overview

The Custorix CRM interface consists of:
- **Navigation Sidebar**: Located on the left side of the screen, provides access to all major modules.
- **Top Bar**: Contains the application title and user menu.
- **Main Content Area**: Displays the content of the selected module.

## Dashboard

The Dashboard provides an overview of key metrics and recent activities across the CRM system.

### Key Features

- **Summary Cards**: Display counts of accounts, contacts, leads, opportunities, support tickets, and invoices.
- **Recent Leads**: Shows the most recently added leads.
- **Recent Opportunities**: Displays the most recent sales opportunities.
- **Recent Support Tickets**: Lists the most recent customer support tickets.

## Accounts Management

The Accounts module allows you to manage your business relationships with companies and organizations.

### Key Features

- **Account List**: View all accounts with filtering and sorting options.
- **Create Account**: Add new business accounts to the system.
- **Account Details**: View and edit comprehensive information about each account.
- **Account Locations**: Manage multiple locations for each account.

### Creating a New Account

1. Navigate to the Accounts page using the sidebar.
2. Click the "New Account" button.
3. Fill in the required information:
   - Account Name
   - Account Number
   - Industry
   - Website
   - Phone
   - Status
4. Add any additional information as needed.
5. Click "Create" to save the new account.

## Contacts Management

The Contacts module allows you to manage individual people associated with your accounts.

### Key Features

- **Contact List**: View all contacts with filtering and sorting options.
- **Create Contact**: Add new contacts to the system.
- **Contact Details**: View and edit comprehensive information about each contact.
- **Primary Contacts**: Designate primary contacts for accounts.
- **Decision Makers**: Identify key decision makers in the organization.

### Creating a New Contact

1. Navigate to the Contacts page using the sidebar.
2. Click the "New Contact" button.
3. Fill in the required information:
   - First Name
   - Last Name
   - Account (company the contact belongs to)
   - Title
   - Email
   - Phone
4. Add any additional information as needed.
5. Click "Create" to save the new contact.
